05 / A little about me

Physics is part of
how I think.

I'm Ahmet, a physicist and software developer. My work moves between computational experiments and tools you can use every day.

In physics, I explore how a model behaves. In software, I care about how an interface feels. Both start with paying attention to the details.

I like making things small enough to understand, useful enough to keep, and open enough to learn from.
